# Wise-plus-grow-project
1.ปัญหาปัจจุบัน

-ข้อมูลสาร รับเข้า–เบิกออก กรอกมือใน Excel ทีละแผนก

-ไฟล์แยกกัน → ซ้ำซ้อน เชื่อมกันไม่ได้ → ทำงานช้า

-เวลาจะหาต้นทุน (ราคาต่อปริมาณ) ต้อง ค้นมือ+กรอกมือ → เสี่ยงผิดพลาด

2.สิ่งที่อยากได้

-โปรแกรมที่กรอกแค่

	-ชื่อสาร + ปริมาณ

	-ดึงราคาจากฐานข้อมูล

	-คำนวณต้นทุนให้ อัตโนมัติ

-ฐานข้อมูลกลาง → ให้ทุกฝ่ายใช้ร่วมกันได้

-ลดการกรอกซ้ำซ้อน

Input (กรอก) → ชื่อสาร, ปริมาณ, หน่วย, วันที่

โยนเข้า staging ผ่าน n8n → ตรวจสอบ + เก็บไฟล์ต้นทาง

โยนไป mapping → Match กับ master (materials, departments) + คำนวณต้นทุน

โยนเข้า core database → เก็บเป็น record จริง + ปรับยอดคลัง

Output → Dashboard/Report/Alert ให้ผู้บริหาร
